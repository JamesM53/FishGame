# FishGame (wip name)
my first little game created in Godot, a 2d fishing game

A 2d fishing game I'm making while learning coding in college

#Features
-Fishing mechanic : cast and catch fish with the mouse
-10 different fish, 5 in each biome
-Each fish has its own rarity
-2 biomes to explore (lake and Ocean)

#Controls
Left mouse to cast
Right mouse to catch

#Planned features
-fish catching mini game
-more fish
-more biomes
-fish are actual objects that can be sold and collected
-fish lenghts
